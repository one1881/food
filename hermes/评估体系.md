| 维度 | 评估重点 | 评估周期 |

## 4. Agent 效果评估（核心）

### 4.1 Agent 质量指标

| 指标 | 定义 | 目标 |
|------|------|------|
| **AI 生成成功率** | 成功生成 / 总请求 | > 90% |
| **一次审核通过率** | 一次通过 / 总审核 | > 85% (V2) |
| **合规评分** | compliance_score | 平均 > 85 |
| **Agent 调用成功率** | 成功 / 总调用 | > 98% |
| **Skills 执行成功率** | 成功 / 总调用 | > 98% |
| **Agent 平均耗时** | 每个 Agent 耗时 | 达标 |

### 4.2 Agent 性能监控（数据库查询）

通过 `agent_skill_logs` 表统计每个子 Agent 和 Skills 的表现：

```sql
SELECT agent_name, skill_name,
    COUNT(*) AS total,
    AVG(duration_ms) AS avg_duration,
    SUM(CASE WHEN status='success' THEN 1 ELSE 0 END)::float / COUNT(*) AS success_rate
FROM agent_skill_logs
WHERE created_at >= NOW() - INTERVAL '30 days'
GROUP BY agent_name, skill_name;
```

### 4.3 质量评估机制（V2）

- **AI 自评：** 生成完成后，Agent 自评质量分数，低于阈值自动重新生成
- **人工抽样：** 按比例抽样人工复核
- **模型评估：** 对比多个 Prompt / 模型版本，择优上线
