## 1. 产品概述

### 1.1 产品定位

为律所业务部提供 **AI 驱动的合同智能生成与审核一体化工作台**。核心采用 **A2A（Agent-to-Agent）多智能体架构 + Skills + MCP 三层融合**：主控 Agent 负责任务编排，多个子 Agent 分工协作（数据接入 / 合同生成 / 合规审核 / 文档处理 / 智能推荐），通过 Skills 执行业务动作、MCP 接入外部工具，自动完成「查数据 → 起草 → 合规审核 → 出文档」的完整链路。

**核心价值：** 将单份合同起草时间从 **2 天缩短到 10 分钟**，全年稳定处理 **2000+ 份合同**。

### 1.2 目标用户

| 用户角色 | 人数规模 | 核心诉求 |
|---------|---------|---------|
| **合同起草人** | 50+ 人 | 快速生成合同初稿，减少重复劳动 |
| **复核人 / 主管** | 5-10 人 | 高效复核团队合同，统一质量标准 |
| **法务审核人员** | 10-20 人 | 结构化审核清单，降低合规风险 |
| **系统管理员** | 1-3 人 | 管理用户权限、模板库、系统配置 |

### 1.3 现状痛点

1. **工具分散** — 合同管理系统、模板库、法规库、Excel 频繁切换
2. **重复劳动** — 每份合同手动查历史案例、对比条款、计算风险
3. **标准不统一** — 不同起草人使用不同模板，格式混乱
4. **合规滞后** — 问题在文书完成后才暴露，反复修改
5. **缺少闭环** — 版本管理混乱，生成依据不可追溯

### 1.4 解决方案

**核心策略：** A2A 多智能体编排 + Skills 业务动作 + MCP 工具接入 + 强制人工审核 + 全流程可追溯

```
统一工作台 + A2A(Skills+MCP) 多智能体 + 结构化审核 + 完整留痕
```

## 2. 用户场景

### 场景 1：合同起草人创建合同

**用户故事：** 作为合同起草人，我希望快速生成合同初稿，而不是从头手写。

**操作流程：**
1. 登录系统，点击"创建合同"
2. 填写关键参数（类型、客户、金额、期限）
3. 点击"AI 生成"，等待 2-4 分钟
4. 查看生成的合同初稿
5. 在富文本编辑器中修改细节
6. 查看右侧智能助手（生成依据、风险提示）
7. 保存草稿或提交审核

**预期结果：** 单份合同起草从 2 天缩短到 10 分钟。

### 场景 2：法务审核人员审核合同

**用户故事：** 作为审核人员，我希望有结构化的检查清单，避免遗漏合规问题。

**操作流程：**
1. 打开"审核中心"，看到待审核列表（徽章提示数量）
2. 点击"开始审核"，弹出审核对话框
3. 左侧预览合同内容（只读）
4. 右侧填写结构化检查清单（数据来源 / 风险提示 / 法规引用 / 格式）
5. 在具体条款上添加批注（V2）
6. 填写总体意见
7. 选择"通过"或"退回修改"

**预期结果：** 审核时间缩短 30%，合规问题前置发现。

### 场景 3：管理员管理模板库

**用户故事：** 作为管理员，我希望统一管理合同模板，保证格式标准化。

**操作流程：**
1. 进入"模板库"
2. 查看公共模板和团队模板
3. 点击"新增模板"，填写模板信息
4. 使用 `{{变量名}}` 定义占位符
5. 保存模板，统计使用次数

**预期结果：** 格式标准统一，新人上手快。

## 7. 风险与依赖

### 7.1 关键依赖

- **大模型 API 稳定性**（Claude）— 核心依赖，需备用方案
- **外部系统对接** — 合同管理系统、法规库 API
- **用户接受度** — 需充分培训与支持

### 7.2 主要风险

| 风险 | 影响 | 应对措施 |
|------|------|---------|
| AI 生成质量不稳定 | 高 | Prompt 优化 + 人工审核兜底 |
| 用户抵触使用 | 高 | 培训 + 保留传统模式 |
| 外部对接失败 | 中 | 降级方案 + 手动录入 |
| V2 范围失控 | 中 | 严守收敛边界，不引入 V1/V2 外能力 |
