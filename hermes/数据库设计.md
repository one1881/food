## 1. 设计原则

- ✅ **V1 基础表** — 支持核心功能（8 张表）
- ✅ **V2 扩展表** — 支持高级功能（新增 4 张表）
- ✅ **统一设计** — 一次设计到位，V1 先实现基础表，V2 补充扩展表

## 2. 核心表设计（V1 实现，8 张）

### 2.1 用户表 (users)

```sql
CREATE TABLE users (
    id SERIAL PRIMARY KEY,
    username VARCHAR(50) UNIQUE NOT NULL,
    password_hash VARCHAR(255) NOT NULL,
    real_name VARCHAR(100) NOT NULL,
    email VARCHAR(100),
    role VARCHAR(20) NOT NULL CHECK (role IN ('drafter', 'supervisor', 'reviewer', 'admin')),
    department VARCHAR(100),
    status VARCHAR(20) DEFAULT 'active' CHECK (status IN ('active', 'inactive')),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
CREATE INDEX idx_users_username ON users(username);
CREATE INDEX idx_users_role ON users(role);
```

### 2.2 合同主表 (contracts)

```sql
CREATE TABLE contracts (
    id SERIAL PRIMARY KEY,
    title VARCHAR(255) NOT NULL,
    contract_type VARCHAR(50) NOT NULL,
    contract_number VARCHAR(100) UNIQUE,
    drafter_id INTEGER REFERENCES users(id) NOT NULL,
    drafter_name VARCHAR(100),
    status VARCHAR(50) DEFAULT 'draft',
    current_version INTEGER DEFAULT 1,
    metadata JSONB,                      -- 客户、金额、期限等参数
    orchestrator_task_id VARCHAR(100),   -- 主控 Agent 任务 ID
    agent_execution_log JSONB,           -- Agent 执行日志
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
CREATE INDEX idx_contracts_drafter ON contracts(drafter_id);
CREATE INDEX idx_contracts_status ON contracts(status);
CREATE INDEX idx_contracts_type ON contracts(contract_type);
CREATE INDEX idx_contracts_metadata ON contracts USING GIN (metadata);
```

**agent_execution_log 结构示例：**
```json
{
  "orchestrator": { "task_id": "task_abc123", "start_time": "...", "end_time": "..." },
  "data_agent":       { "status": "success", "duration": 5.2, "skills_used": ["get_customer_info"] },
  "generation_agent": { "status": "success", "duration": 245.8, "tokens": 5000 },
  "compliance_agent": { "status": "success", "duration": 8.5, "risk_score": 85 }
}
```

### 2.3 合同版本表 (contract_versions)

```sql
CREATE TABLE contract_versions (
    id SERIAL PRIMARY KEY,
    contract_id INTEGER REFERENCES contracts(id) ON DELETE CASCADE NOT NULL,
    version_number INTEGER NOT NULL,
    content TEXT NOT NULL,
    content_docx VARCHAR(500),
    generation_context JSONB,   -- 生成时使用的上下文（可追溯）
    agent_skills_log JSONB,     -- Skills 执行日志
    created_by INTEGER REFERENCES users(id),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    change_summary TEXT,
    UNIQUE (contract_id, version_number)
);
CREATE INDEX idx_versions_contract ON contract_versions(contract_id);
```

**generation_context 结构：**
```json
{
  "customer_data": { "name": "A公司", "industry": "科技", "source": "data_agent.get_customer_info" },
  "historical_contracts": [ { "id": 101, "similarity": 0.85 } ],
  "regulations": [ { "name": "合同法", "article": "第XX条" } ],
  "user_requirements": "需要添加违约责任条款"
}
```

### 2.4 审核流程表 (workflow_records)

```sql
CREATE TABLE workflow_records (
    id SERIAL PRIMARY KEY,
    contract_id INTEGER REFERENCES contracts(id) ON DELETE CASCADE NOT NULL,
    version_id INTEGER REFERENCES contract_versions(id),
    from_status VARCHAR(50),
    to_status VARCHAR(50),
    operator_id INTEGER REFERENCES users(id) NOT NULL,
    operator_name VARCHAR(100),
    action VARCHAR(50),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
CREATE INDEX idx_workflow_contract ON workflow_records(contract_id);
```

### 2.5 审核意见表 (review_opinions)

```sql
CREATE TABLE review_opinions (
    id SERIAL PRIMARY KEY,
    contract_id INTEGER REFERENCES contracts(id) ON DELETE CASCADE NOT NULL,
    version_id INTEGER REFERENCES contract_versions(id),
    reviewer_id INTEGER REFERENCES users(id) NOT NULL,
    reviewer_name VARCHAR(100),
    review_type VARCHAR(20),
    compliance_result JSONB,   -- 合规审核子 Agent 结果
    checklist_result JSONB,    -- 结构化检查清单
    comments TEXT,
    decision VARCHAR(20),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
CREATE INDEX idx_review_contract ON review_opinions(contract_id);
```

**compliance_result 结构：**
```json
{
  "risks": [ { "type": "付款条款不明确", "severity": "medium", "location": "第三条", "suggestion": "建议明确付款时间" } ],
  "regulation_compliance": { "合同法": true, "民法典": true },
  "compliance_score": 85,
  "agent": "compliance_agent"
}
```

### 2.6 模板表 (templates)

```sql
CREATE TABLE templates (
    id SERIAL PRIMARY KEY,
    name VARCHAR(255) NOT NULL,
    contract_type VARCHAR(50) NOT NULL,
    content TEXT NOT NULL,
    variables JSONB,
    scope VARCHAR(20) DEFAULT 'public',
    created_by INTEGER REFERENCES users(id),
    usage_count INTEGER DEFAULT 0,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
CREATE INDEX idx_templates_type ON templates(contract_type);
```

### 2.7 Agent 任务表 (agent_tasks) — 核心可追溯

```sql
CREATE TABLE agent_tasks (
    id SERIAL PRIMARY KEY,
    task_id VARCHAR(100) UNIQUE NOT NULL,
    task_type VARCHAR(50) NOT NULL,   -- generate_contract, review_contract
    contract_id INTEGER REFERENCES contracts(id),
    status VARCHAR(20) DEFAULT 'pending',  -- pending, running, completed, failed
    progress INTEGER DEFAULT 0,            -- 0-100
    orchestrator_agent VARCHAR(50),
    sub_agents JSONB,                      -- 涉及的子 Agent 列表
    started_at TIMESTAMP,
    completed_at TIMESTAMP,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    result JSONB,
    error_message TEXT
);
CREATE INDEX idx_agent_tasks_status ON agent_tasks(status);
CREATE INDEX idx_agent_tasks_contract ON agent_tasks(contract_id);
```

### 2.8 Agent Skills 执行日志表 (agent_skill_logs) — 核心可追溯

```sql
CREATE TABLE agent_skill_logs (
    id SERIAL PRIMARY KEY,
    task_id VARCHAR(100) REFERENCES agent_tasks(task_id),
    agent_name VARCHAR(50) NOT NULL,
    skill_name VARCHAR(100) NOT NULL,
    status VARCHAR(20) NOT NULL,       -- success, failed
    started_at TIMESTAMP NOT NULL,
    completed_at TIMESTAMP,
    duration_ms INTEGER,
    input_params JSONB,
    output_result JSONB,
    error_message TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
CREATE INDEX idx_skill_logs_task ON agent_skill_logs(task_id);
CREATE INDEX idx_skill_logs_agent ON agent_skill_logs(agent_name);
```

## 3. 扩展表设计（V2 新增，4 张）

### 3.1 批注表 (annotations)
```sql
CREATE TABLE annotations (
    id SERIAL PRIMARY KEY,
    contract_id INTEGER REFERENCES contracts(id) ON DELETE CASCADE NOT NULL,
    version_id INTEGER REFERENCES contract_versions(id),
    anchor_text VARCHAR(500),
    anchor_position INTEGER,
    content TEXT NOT NULL,
    annotation_type VARCHAR(20) DEFAULT 'comment',
    created_by INTEGER REFERENCES users(id) NOT NULL,
    creator_name VARCHAR(100),
    status VARCHAR(20) DEFAULT 'open',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### 3.2 历史合同库表 (historical_contracts) — 支撑智能推荐

```sql
CREATE TABLE historical_contracts (
    id SERIAL PRIMARY KEY,
    contract_number VARCHAR(100) UNIQUE NOT NULL,
    title VARCHAR(255) NOT NULL,
    contract_type VARCHAR(50) NOT NULL,
    content TEXT NOT NULL,
    summary TEXT,
    parties JSONB,
    amount DECIMAL(15,2),
    signed_date DATE,
    quality_score INTEGER,
    has_disputes BOOLEAN DEFAULT false,
    embedding VECTOR(1536),   -- pgvector 向量，用于相似检索
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
CREATE INDEX idx_historical_type ON historical_contracts(contract_type);
CREATE INDEX idx_historical_embedding ON historical_contracts USING ivfflat (embedding vector_cosine_ops) WITH (lists = 100);
```

### 3.3 法规库表 (regulations) — 支撑合规审核

```sql
CREATE TABLE regulations (
    id SERIAL PRIMARY KEY,
    regulation_name VARCHAR(255) NOT NULL,
    article_number VARCHAR(50),
    content TEXT NOT NULL,
    category VARCHAR(50),
    applicable_types JSONB,
    effective_date DATE,
    status VARCHAR(20) DEFAULT 'active',
    embedding VECTOR(1536),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
CREATE INDEX idx_regulations_category ON regulations(category);
```

### 3.4 智能推荐记录表 (recommendations)
```sql
CREATE TABLE recommendations (
    id SERIAL PRIMARY KEY,
    contract_id INTEGER REFERENCES contracts(id) ON DELETE CASCADE NOT NULL,
    recommendation_type VARCHAR(50) NOT NULL,  -- similar_case, standard_clause, risk_warning
    title VARCHAR(255) NOT NULL,
    content TEXT,
    relevance_score DECIMAL(5,2),
    generated_by_agent VARCHAR(50),
    generated_by_skill VARCHAR(100),
    user_feedback VARCHAR(20),   -- accepted, rejected, ignored
    feedback_at TIMESTAMP,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

## 6. 核心查询示例

### 6.1 查询合同生成进度
```sql
SELECT t.task_id, t.status, t.progress,
    t.sub_agents->>'data_agent'->>'status' AS data_agent_status,
    t.sub_agents->>'generation_agent'->>'status' AS generation_agent_status
FROM agent_tasks t
WHERE t.contract_id = $1
ORDER BY t.created_at DESC LIMIT 1;
```

### 6.2 查询 Agent Skills 性能统计
```sql
SELECT agent_name, skill_name,
    COUNT(*) AS total_executions,
    AVG(duration_ms) AS avg_duration_ms,
    SUM(CASE WHEN status='success' THEN 1 ELSE 0 END)::float / COUNT(*) AS success_rate
FROM agent_skill_logs
WHERE created_at >= NOW() - INTERVAL '7 days'
GROUP BY agent_name, skill_name
ORDER BY avg_duration_ms DESC;
```

### 6.3 查询相似历史合同（V2 智能推荐）
```sql
SELECT id, title, contract_type,
    1 - (embedding <=> $1::vector) AS similarity
FROM historical_contracts
WHERE contract_type = $2
ORDER BY embedding <=> $1::vector LIMIT 5;
```
