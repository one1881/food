# 合同智能生成与法务审核工作台 - 版本规划

**文档版本：** v3.0（A2A + Skills + MCP 融合版）
**创建日期：** 2026-08-19
**规划周期：** 2026 Q3 - 2027 Q1
**最后更新：** 2026-08-19

---

## 1. 版本策略

### 1.1 版本定义

采用**渐进式交付**策略，分 **V1（骨架版）** 和 **V2（精细化版）** 两个版本，**A2A + Skills + MCP** 三层架构贯穿始终，逐步开发、逐步深化。

| 版本 | 定位 | 核心目标 | 周期 |
|------|------|---------|------|
| **V1（骨架版）** | 最小可行产品 | 跑通「主控 Agent + 3 子 Agent」完整闭环，快速上线验证 | 3 个月 |
| **V2（精细化版）** | 完整产品 | 扩至 5 子 Agent，补全 Skills/MCP，增强质量与体验 | +4.5 个月 |

### 1.2 版本哲学

```
V1：能用 > 好用 —— A2A 主干 + 3 子 Agent + 基础 Skills/MCP 先跑通闭环
V2：好用 > 完美 —— 扩至 5 子 Agent + 完整 Skills/MCP + 质量评估
```

> **核心原则：** A2A 是编排主轴，Skills 是业务动作，MCP 是工具接入。三层贯穿 V1/V2，V2 只在数量与精细化上升级，不做推倒重构。

## 3. V1（骨架版）详细规划

### 3.1 目标与范围

**核心目标：** 3 个月内跑通「主控 Agent + 3 子 Agent」的完整闭环，验证商业模式。

**子 Agent：3 个**
1. 数据接入子 Agent
2. 合同生成子 Agent
3. 合规审核子 Agent

**Skills：约 9 个**（每个子 Agent 内聚 3 个）

**MCP：3 个**
1. 数据源 MCP（客户资料、历史合同、法规库）
2. 合同知识 MCP（模板库、条款库）
3. 合规审核 MCP（法规引用、风险规则）

**核心功能：**
- ✅ 登录认证（JWT）
- ✅ 合同 CRUD
- ✅ AI 生成合同初稿（A2A 闭环）
- ✅ 基础富文本编辑（Textarea）
- ✅ 审核流程（草稿 → 待复核 → 待审核 → 已完成）
- ✅ 结构化审核清单
- ✅ 模板管理（公共 / 团队）
- ✅ 基础版本管理
- ✅ Word 导出

**暂不包含：** 高级富文本、批注、版本对比、PDF、实时协作、电子签章、移动端

### 3.2 V1 核心流程

```
用户填写参数
  → 主控 Agent 接收任务
  → 数据接入子 Agent（并行 3 Skills：查客户 / 查历史 / 查法规，经数据源 MCP）
  → 合同生成子 Agent（经合同知识 MCP 取模板，调用大模型生成初稿）
  → 合规审核子 Agent（并行 3 Skills：风险 / 法规 / 评分，经合规审核 MCP）
  → 主控 Agent 聚合结果
  → 前端展示 → 用户编辑 → 保存草稿
```

### 3.3 开发计划（V1）

| 阶段 | 时间 | 里程碑 | 负责 |
|------|------|--------|------|
| 阶段 1 | 2 周 | 项目初始化、数据库设计、用户认证 | 后端 |
| 阶段 2 | 3 周 | 合同 CRUD、A2A 编排骨架、前端框架 | 全员 |
| 阶段 3 | 2 周 | 3 子 Agent + 9 Skills + 3 MCP 实现 | 后端 |
| 阶段 4 | 2 周 | 审核工作流、模板管理、版本管理 | 全员 |
| 阶段 5 | 2 周 | Word 导出、测试、部署 | 全员 |
| 阶段 6 | 1 周 | 用户培训、试运行 | 产品 |

**总计：12 周（约 3 个月）**

## 4. V2（精细化版）详细规划

### 4.1 目标与范围

**核心目标：** V1 上线后 4.5 个月内迭代，扩至 5 子 Agent，补全 Skills/MCP，引入质量评估与决策优化。

**子 Agent：5 个**（新增 2 个）
1. 数据接入子 Agent
2. 合同生成子 Agent
3. 合规审核子 Agent
4. **文档处理子 Agent**（新增：Word/PDF 生成、版本对比、附件包）
5. **智能推荐子 Agent**（新增：相似案例、标准条款、风险预警）

**Skills：约 17 个**

**MCP：5 个**（新增 2 个）
1. 数据源 MCP
2. 合同知识 MCP
3. 合规审核 MCP
4. **文档导出 MCP**（新增：PDF/Word 导出）
5. **系统配置 MCP**（新增：模板/阈值/风险等级配置）

**新增能力：**
- ✅ 高级富文本编辑器（Quill.js）
- ✅ 批注功能
- ✅ 版本对比（高亮差异）
- ✅ PDF 导出
- ✅ 智能推荐（相似案例、标准条款、风险预警）
- ✅ 数据统计报表
- ✅ 质量评估（生成后 AI 自评，低于阈值自动重新生成）
- ✅ 决策优化（基于历史数据优化任务分配）

**V2 不引入（收敛边界）：** 实时协作、电子签章、移动端、多租户、审批流引擎——这些留到 V1/V2 之后，避免范围失控。

### 4.2 架构升级（V2）

```
V1：主控 Agent + 3 子 Agent + 9 Skills + 3 MCP + 自研 asyncio 编排
V2：主控 Agent + 5 子 Agent + 17 Skills + 5 MCP + 成熟编排框架（LangGraph）
    新增：质量评估、决策优化、Skills 热插拔
```

### 4.3 开发计划（V2）

| 阶段 | 时间 | 里程碑 | 负责 |
|------|------|--------|------|
| 阶段 1 | 2 周 | Agent 架构升级、Skills/MCP 补全 | 后端 |
| 阶段 2 | 3 周 | 文档处理子 Agent、高级富文本 | 全员 |
| 阶段 3 | 2 周 | 版本对比、PDF 导出 | 全员 |
| 阶段 4 | 3 周 | 智能推荐子 Agent、数据统计 | 后端 |
| 阶段 5 | 2 周 | 批注功能、质量评估 | 全员 |
| 阶段 6 | 2 周 | 测试、优化、上线 | 全员 |

**总计：18 周（约 4.5 个月）**
